# WITS Tools Capture

These optional browser extensions adapt the selected-tab capture workflow from the OpenDownload project, which distributes its code under the MIT license.

- Open **Crawler → Media Downloads → Selected-tab capture** to register the native bridge and enable capture.
- For Chrome or Edge, load the `chromium` directory as an unpacked extension. For Firefox Developer Edition or Zen, load `firefox/manifest.json` as a temporary extension.
- In the selected tab, open the extension, start capture, and play media you are authorized to save. Select a detected source in WITS Tools.
- Use manual pairing if native messaging is unavailable. The displayed code expires after five minutes for initial pairing.
